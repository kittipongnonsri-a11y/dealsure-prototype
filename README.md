# ดีลชัวร์ (DealSure) – ต้นแบบทดลอง

แอปคนกลางพักเงิน สำหรับคนซื้อขายในกลุ่ม Facebook และ LINE
**นี่คือเวอร์ชันทดลอง ไม่มีเงินจริง** ทุกขั้นตอนการจ่ายเงิน, OTP, การยืนยันตัวตน และขนส่ง เป็นการจำลองทั้งหมด

---

## วิธีเปิดใช้งาน (ง่ายที่สุด)

ต้องมีแค่ Python 3 (เวอร์ชัน 3.9 ขึ้นไป) ไม่ต้องติดตั้งอะไรเพิ่ม

```bash
cd dealsure-app
./start.sh            # เปิดเซิร์ฟเวอร์ไว้เบื้องหลัง
```

จากนั้นเปิดเบราว์เซอร์ไปที่ **http://localhost:8787**

คำสั่งอื่น ๆ

| ต้องการ | คำสั่ง |
|---|---|
| เปิดแบบเห็นข้อความในหน้าจอ | `python3 server.py` |
| เปลี่ยนพอร์ต | `PORT=9000 ./start.sh` |
| ล้างข้อมูลทั้งหมด แล้วเริ่มใหม่ด้วยข้อมูลตัวอย่าง | `./reset-demo.sh` |
| ปิดเซิร์ฟเวอร์ | `pkill -f "python3 server.py"` |
| ดูบันทึกการทำงาน | เปิดไฟล์ `data/server.log` |

ข้อมูลทั้งหมดเก็บในไฟล์ `data/dealsure.db` (SQLite) และรูป/วิดีโอใน `data/uploads/`

## หน้าผู้ดูแล (ตัดสินข้อพิพาท)

- ที่อยู่: **http://localhost:8787/admin**
- รหัสผ่าน: ตั้งด้วยตัวแปร `ADMIN_PASSWORD` (บน Render ตั้งไว้ในหน้า Environment ของบริการ – ไม่เก็บในโค้ด)
- เครื่องตัวเอง: `ADMIN_PASSWORD=รหัสของคุณ ./start.sh`
- ถ้าไม่ได้ตั้ง เซิร์ฟเวอร์จะสุ่มรหัสใหม่ทุกครั้งที่เปิด แล้วพิมพ์ไว้ใน log (บรรทัด `[admin] ...`) และเก็บไว้ที่ `data/admin_password.txt`

ในหน้านี้ทำได้: ดูหลักฐาน (รูป/วิดีโอ) ของข้อพิพาท แล้วเลือก "คืนเงินผู้ซื้อทั้งหมด" / "โอนให้ผู้ขาย" / "คืนบางส่วน",
ดูรายการรอโอนให้ผู้ขาย และกด "จำลองรอบโอนวันนี้"

## บัญชีตัวอย่าง (ข้อมูลปลอมทั้งหมด)

เข้าสู่ระบบด้วยชื่ออะไรก็ได้ + เบอร์ด้านล่าง รหัส OTP จะโชว์บนหน้าจอเลย

| เบอร์ | เป็นใคร |
|---|---|
| 0800000001 | ป้าแดง (ตัวอย่าง) – ร้านระดับ **Gold** 139 ดีล ⭐ 4.8 (มีช่องทางโซเชียลตัวอย่าง · Facebook ติดป้าย "ตรวจแล้ว") |
| 0800000002 | มิ้นท์ (ตัวอย่าง) – ร้านระดับ **Silver** 29 ดีล ⭐ 4.6 |
| 0899000001–0899000012 | ผู้ซื้อตัวอย่าง |
| เบอร์อื่น ๆ | จะเป็นผู้ใช้ใหม่ (วงเงิน 5,000 ฿/ดีล) |

## ทดลองกับ 2 เครื่อง

1. เครื่องแรก (ผู้ขาย) เข้าสู่ระบบ → "สร้างดีล" → กรอกสินค้า ราคา วิธีส่ง → ได้ลิงก์ → กด "คัดลอก" หรือ "ส่งทาง LINE"
2. เครื่องที่สอง (ผู้ซื้อ) เปิดลิงก์ → เข้าสู่ระบบด้วยเบอร์อื่น → ดูโปรไฟล์ผู้ขาย → "ยอมรับดีล" → หน้าพร้อมเพย์ทดลอง → กด **"จำลองว่าจ่ายแล้ว"** → เงินขึ้นสถานะ "พักไว้"
3. ผู้ขายกรอกเลขพัสดุ (หรือแนบหลักฐานแมสเซนเจอร์ / ถ้านัดรับ ผู้ขายจะเห็นรหัส 4 หลักให้ผู้ซื้อกรอกตอนรับของ)
4. ผู้ซื้อกด "ได้รับของแล้ว ปล่อยเงิน" → ให้ดาวรีวิว → ผู้ขายเห็น "รอโอนรอบถัดไป (วันละครั้ง)"

> ทั้งสองเครื่องต้องเข้าถึงเซิร์ฟเวอร์เดียวกันได้ เช่น อยู่ Wi-Fi เดียวกันแล้วเปิด `http://<IP ของคอมพิวเตอร์>:8787`
> หรือเอาขึ้นโฮสต์ฟรี (ดูด้านล่าง)

**ปุ่มทดสอบ:** ในหน้าดีลมีกล่อง "เครื่องมือทดสอบ" ให้กด **"เร่งเวลา (ทดสอบ)"** +1 วัน / +3 วัน
เพื่อดูการปล่อยเงินอัตโนมัติ, การหมดเวลาเปิดข้อพิพาท, หรือการส่งช้าเกินกำหนด และปุ่ม "จำลอง: ขนส่งแจ้งว่าของถึงแล้ว"

## ฟีเจอร์ใหม่ (v2)

- **รูปโปรไฟล์** – หน้า "บัญชี" แตะรูปหรือปุ่ม "เปลี่ยนรูปโปรไฟล์" → เลือกรูป → ลากจัดตำแหน่ง/ซูม (ตัดเป็นสี่เหลี่ยมจัตุรัส 512×512 ในเครื่อง) →
  "ใช้รูปนี้" · รูปขึ้นทุกที่: บัญชี, โปรไฟล์, หน้าดีล, หน้าร้าน, ร้านแนะนำ, การ์ดดีล, แชท, รีวิว · ปุ่ม "ใช้รูปเริ่มต้น" กลับไปเป็นวงกลมตัวอักษรย่อ
- **แชทผู้ซื้อ–ผู้ขายในทุกดีล** – การ์ด "แชทกับผู้ขาย/ผู้ซื้อ" ในหน้าดีล (เปิดได้เมื่ออีกฝ่ายกดรับดีลแล้ว) ส่งข้อความ + รูป (ครั้งละ ≤4 รูป)
  มีปุ่ม "เต็มจอ" · ข้อความใหม่เด้งเองทุก 4 วินาที · มีคำเตือน "จ่ายผ่านดีลชัวร์เท่านั้น อย่าโอนนอกแอป" และถ้าข้อความพูดถึงเลขบัญชี/โอนตรง จะมีป้ายเตือนใต้ข้อความ
- **แท็บ "แชท"** ที่แถบล่าง – รวมห้องแชททั้งหมด (ดีล · ทักร้าน · ทีมงาน) พร้อมตัวเลขข้อความยังไม่อ่าน · หน้าแรกมีแถบ "มีข้อความใหม่" และการ์ดดีลมีตัวเลขแชท
  · ทุกข้อความใหม่เข้ากระดิ่งแจ้งเตือน (รวมเป็น 1 รายการต่อห้องจนกว่าจะอ่าน กระดิ่งจะได้ไม่รก)
- **ทักร้านก่อนซื้อ** – ปุ่ม "ทักร้าน" ในหน้าร้าน
- **ทีมงานคุยในข้อพิพาท** – หน้าแอดมิน แต่ละข้อพิพาทมีกล่อง "ข้อความถึงผู้ซื้อและผู้ขาย" (แนบรูปได้ · มีแชทระหว่างผู้ซื้อ–ผู้ขายให้เปิดดูเป็นหลักฐาน)
  ข้อความแอดมินขึ้นชื่อ **ทีมงานดีลชัวร์** + ป้าย "ทีมงาน" · ผู้ซื้อและผู้ขายเห็นในการ์ด "ข้อความจากทีมงานดีลชัวร์" ในหน้าดีล + ได้แจ้งเตือน
  ตอบกลับและแนบรูปได้ · เมื่อแอดมินตัดสินแล้ว ห้องนี้ปิด (อ่านย้อนหลังได้)
- **การ์ด "ดีลล่าสุด" แบบใหม่** ในหน้าแรก – การ์ดสูงตามเนื้อหา ชื่อสินค้าได้ 2 บรรทัด, ราคา / สถานะ / อีกฝ่าย (พร้อมรูป) / วันที่อัปเดต แยกบรรทัด

> หมายเหตุ: บน Render แผนฟรี ดิสก์ไม่ถาวร รูปโปรไฟล์/รูปในแชทที่อัปโหลด (และข้อมูลทั้งหมด) จะหายเมื่อเซิร์ฟเวอร์รีสตาร์ต ดีพลอยใหม่ หรือหลับ — ใช้ทดลองได้ แต่ถ้าใช้จริงต้องมีดิสก์ถาวร/ที่เก็บไฟล์

## ฟีเจอร์ใหม่ (v3): ดีลที่พัก 🏠

แก้ปัญหา "จองที่พักจากโพสต์ FB / LINE แล้วเจอที่พักปลอม" — **เงินพักไว้จนผู้เข้าพักเช็คอินได้จริง**

- **เลือกประเภทดีล** ตอนสร้าง: `สินค้า` (แบบเดิม) หรือ `ที่พัก` (หรือกดการ์ด "ดีลที่พัก" ในหน้าแรก) · เจ้าของที่พักหรือผู้เข้าพักเป็นคนเริ่มก็ได้ ส่งลิงก์แบบเดิม
- **ข้อมูลที่พัก:** ชื่อที่พัก · ที่อยู่ · ลิงก์ Google Maps (บังคับ ตรวจว่าเป็นลิงก์ Google Maps) · รูป · วัน+เวลาเช็คอิน · วันเช็คเอาต์ (คิดจำนวนคืนให้) · จำนวนผู้เข้าพัก ·
  ราคารวม · ชื่อผู้ติดต่อของที่พัก · ยกเลิกฟรีได้ถึงกี่วันก่อนเช็คอิน (ค่าเริ่มต้น 3) · ค่าธรรมเนียม 2% (ขั้นต่ำ 20) / วงเงิน / กฎยืนยันตัวตน เหมือนเดิม
- **สถานะ:** รอจ่าย → **พักเงินแล้ว (รอเช็คอิน)** พร้อมนับถอยหลังถึงเวลาเช็คอิน → วันเช็คอิน ผู้เข้าพักกด **"เช็คอินแล้ว ที่พักตรงปก"**
  หรือกรอก **รหัสเช็คอิน 4 หลัก** ที่แสดงให้เจ้าของที่พัก → ปล่อยเงินทันที
- **ปล่อยเงินอัตโนมัติ 24 ชม. หลังเวลาเช็คอิน** ถ้าผู้เข้าพักไม่ยืนยันและไม่แจ้งปัญหา
- **ปุ่ม "ไม่มีที่พักจริง / ไม่ตรงปก / เข้าพักไม่ได้"** ใช้ได้ตั้งแต่เวลาเช็คอินจนถึงเวลาปล่อยเงินอัตโนมัติ · ต้องแนบรูป/วิดีโอ + บอกตำแหน่งที่อยู่ตอนนี้
  (มีปุ่มใส่พิกัด GPS) · เงินยังพักไว้ → เข้าระบบข้อพิพาท + ทีมงานคุยกับทั้งสองฝ่ายแบบเดิม (หน้าแอดมินแสดงที่อยู่ตามประกาศ ลิงก์แผนที่ เวลาเช็คอิน และตำแหน่งที่ผู้เข้าพักแจ้ง)
- **ยกเลิกก่อนเช็คอิน:** ผู้เข้าพักยกเลิกในช่วงยกเลิกฟรี = คืนเงินเต็ม · หลังจากนั้น = ส่งทีมงานตัดสิน (คืนเต็ม/บางส่วน/ปล่อยเงิน) ·
  เจ้าของที่พักยกเลิกเมื่อไรก็ได้ = คืนเงินผู้เข้าพักเต็มจำนวน
- **ความน่าเชื่อถือ:** หน้าดีลที่พักโชว์การ์ดเจ้าของที่พักไว้บนสุด (ยืนยันตัวตน · ระดับร้าน · ดาว · จำนวนเข้าพักสำเร็จ · อัตราข้อพิพาท · ใช้งานมานานเท่าไร
  + คำเตือนถ้ายังไม่ยืนยันตัวตน/บัญชีใหม่) และเคล็ดลับกันที่พักปลอม (เช็คแผนที่ · ขอวิดีโอคอลดูห้อง · ห้ามจ่ายนอกแอป)
- **สินค้าขายประจำ:** หน้าร้านโชว์การ์ดเล็กประมาณ 4 ชิ้น + ปุ่ม "ดูทั้งหมด" · เจ้าของกด "เพิ่มสินค้าขายประจำ" ให้ลูกค้าสั่งซื้อแบบปลอดภัยซ้ำได้ง่าย
- **ที่พักในหน้าร้าน:** เจ้าของกด "เพิ่มที่พัก" (ราคาต่อคืน · เวลาเช็คอิน · ผู้เข้าพักสูงสุด · ยกเลิกฟรี) ลูกค้ากด "จองแบบปลอดภัย" เลือกวันเช็คอิน/จำนวนคืน/ผู้เข้าพัก
- **ตัวอย่าง:** เจ้าของที่พักปลอม **พี่ปุ้ย (ตัวอย่าง)** – "บ้านพักริมดอย แม่ริม (ตัวอย่าง)" ร้านระดับ Silver มีที่พัก 2 แห่ง + ประวัติเข้าพักสำเร็จ 34 ครั้ง (เบอร์ 0800000003)
  · ฐานข้อมูลเดิมจะถูกเพิ่มตัวอย่างนี้ให้อัตโนมัติเมื่อเปิดเซิร์ฟเวอร์
- **เครื่องมือทดสอบ:** "เร่งเวลา (ทดสอบ) → ถึงเวลาเช็คอิน" และ "→ เลยเวลาปล่อยเงินอัตโนมัติ" (+1 วัน / +3 วัน ยังมีเหมือนเดิม)

## ฟีเจอร์ใหม่ (v4): ช่องทางโซเชียล + รีวิวแบบสรุป

- **ช่องทางโซเชียล / ติดต่อ** – หน้า "บัญชี" มีการ์ดใหม่: Facebook · LINE ID/ลิงก์ · Instagram · TikTok · YouTube · เว็บไซต์ · เบอร์โทรติดต่อ (ทุกช่องไม่บังคับ)
  · พิมพ์ชื่อผู้ใช้หรือวางลิงก์ก็ได้ ระบบตรวจและจัดรูปแบบให้ เช่น `m.facebook.com/abc?ref=x` → `abc`, `@ShopA` (LINE OA) → `line.me/R/ti/p/@shopa`,
    `instagram.com/Shop.A/?igsh=…` → `@shop.a`, `+66 81 234 5678` → `081-234-5678` (กดแล้วโทรออก) · รูปแบบผิดจะขึ้นข้อความสีแดงใต้ช่องนั้น และไม่บันทึกทั้งชุด
  · ลิงก์อันตราย (`javascript:` ฯลฯ) และลิงก์โซเชียลที่ใส่ผิดช่องถูกปฏิเสธ · ส่งค่าว่าง = ลบช่องนั้น
  · แสดงเป็นปุ่มไอคอนสีแบรนด์บน **โปรไฟล์สาธารณะ** และ **หน้าร้าน** กดแล้วเปิดแอป/เว็บที่ถูกต้อง (เบอร์โทร = `tel:`)
  · มีหมายเหตุ "ช่องทางที่เจ้าของบัญชีกรอกเอง ยังไม่ได้ตรวจสอบ · คุยได้ แต่จ่ายเงินผ่านดีลชัวร์เท่านั้น"
  · ทีมงานติ๊ก "ตรวจแล้ว" ให้ทีละช่องได้ด้วย API `POST /api/admin/users/<id>/socials/verify {"key":"facebook","verified":true}` (ต้องล็อกอินแอดมิน)
    ถ้าเจ้าของเปลี่ยนลิงก์ ป้าย "ตรวจแล้ว" ของช่องนั้นหายเอง (ยังไม่มีปุ่มในหน้าแอดมิน)
- **รีวิวแบบสรุป** (หน้าร้าน + โปรไฟล์) – ด้านบนมี ดาวเฉลี่ย · จำนวนรีวิว · แท่งกระจายดาว (แตะแท่งเพื่อกรองได้) แล้วแสดงแค่ **3 รีวิวที่สำคัญที่สุด**
  + ปุ่ม **"ดูรีวิวทั้งหมด (N)"** → โหลดเพิ่มทีละ 10 ("ดูเพิ่ม (อีก X รีวิว)")
  · "สำคัญที่สุด" = มีรูป · เขียนละเอียด · ใหม่ · ดีลมูลค่าสูง และ **ดันรีวิวติชม (1–2 ดาว) ล่าสุดขึ้นมาใน 3 อันดับแรกเสมอ** (ป้าย "รีวิวติชมล่าสุด") เพื่อความโปร่งใส
  · ตัวกรอง: ทั้งหมด · 5 ดาว · 4 ดาว · 1–3 ดาว (ติชม) · มีรูป · สินค้า · ที่พัก (มีจำนวนกำกับ หมวดที่ไม่มีรีวิวกดไม่ได้) · เรียง: สำคัญที่สุด / ล่าสุด
  · API: `GET /api/users/<id>/reviews?role=seller&filter=all|5|4|low|photos|goods|stay&sort=important|recent&offset=0&limit=10`
- **แนบรูปในรีวิว** (ไม่บังคับ สูงสุด 3 รูป) ได้ทั้งตอนกด "ให้คะแนน", ตอนยืนยันรับของ และตอนยืนยันเช็คอิน · ข้อความรีวิวยาวได้ 500 ตัวอักษร
- **รีวิวตัวอย่าง** (ติดป้าย "รีวิวตัวอย่าง" + ข้อความลงท้าย "(รีวิวตัวอย่าง)") ให้ลองตัวกรองได้: รีวิวมีรูป ยาว ติชม 1–3 ดาว ในร้านระดับ Gold/Silver
  และเจ้าของที่พักตัวอย่างมีทั้งรีวิว "สินค้า" (กาแฟดอยตัวอย่าง) และ "ที่พัก" · ฐานข้อมูลเดิมจะถูกเพิ่มตัวอย่างนี้ให้อัตโนมัติเมื่อเปิดเซิร์ฟเวอร์

## กติกาที่ตั้งไว้ในต้นแบบนี้

- ค่าธรรมเนียม 2% ขั้นต่ำ 20 ฿ เลือกได้ว่าผู้ซื้อจ่าย / ผู้ขายจ่าย / คนละครึ่ง
- ยอดดีลขั้นต่ำ 100 ฿ (สร้างดีล + สั่งซื้อ/จองจากหน้าร้าน)
- ค่าโอนออก 30 ฿/วัน ผู้ขายจ่าย หักจากยอดโอนรวมรายวัน (วันละ 1 ครั้ง) ฟรีเมื่อยอดรวม ≥ 1,000 ฿
- ผู้ซื้อยกเลิกเอง (ก่อนผู้ขายส่งของ / ผู้เข้าพักยกเลิกในช่วงยกเลิกฟรี) = ค่าดำเนินการ 2% ของยอดที่จ่าย ขั้นต่ำ 10 ฿
- ผู้ขาย/เจ้าของผิด (ยกเลิก ส่งไม่ทัน ทีมงานตัดสินให้ผู้ซื้อ) = ผู้ซื้อได้คืนเต็ม + ค่าปรับผู้ขายเท่าค่าธรรมเนียม หักจากยอดโอนถัดไป
- คืนบางส่วน = ค่าธรรมเนียมคิดจากยอดที่ผู้ขายได้จริง (ขั้นต่ำ 20 ฿)
- ผู้ขายส่งของ/ส่งมอบแล้ว ผู้ซื้อยกเลิกไม่ได้ (ยืนยันรับของ หรือแจ้งปัญหาเท่านั้น)
- ผู้ใช้ใหม่ วงเงินไม่เกิน 5,000 ฿/ดีล (ผู้ซื้อที่ทำดีลสำเร็จครบ 5 ครั้งปลดล็อกเป็น 50,000 ฿)
- ดีลเกิน 3,000 ฿ ต้องยืนยันตัวตน (อัปโหลดบัตรจำลอง อนุมัติอัตโนมัติ – ทดลอง)
- ระดับร้าน: **Bronze** 5,000 ฿ · **Silver** (20 ดีล+, ⭐4.5+, ข้อพิพาท ≤5%) 20,000 ฿ · **Gold** (100 ดีล+, ⭐4.7+, ข้อพิพาท ≤2%) 50,000 ฿
- ปล่อยเงินอัตโนมัติ: ส่งพัสดุ 3 วันหลังของถึง · แมสเซนเจอร์ 24 ชม. · นัดรับ ปล่อยทันทีเมื่อกรอกรหัสถูก
- เปิดข้อพิพาทได้ภายใน 3 วันหลังของถึง (และก่อนปล่อยเงินอัตโนมัติ) พร้อมเหตุผล + รูป/วิดีโอ เงินจะถูกพักไว้จนผู้ดูแลตัดสิน
- ถ้าเลยวันส่งที่ตกลงแล้วผู้ขายยังไม่ส่ง ผู้ซื้อกดขอเงินคืนได้ทันที
- ดีลที่พัก: ปล่อยเงินเมื่อผู้เข้าพักยืนยันเช็คอิน/กรอกรหัส หรืออัตโนมัติ 24 ชม. หลังเวลาเช็คอิน · แจ้งปัญหาได้ตั้งแต่เวลาเช็คอินจนถึงเวลาปล่อยเงิน

## เอาขึ้นโฮสต์ฟรี (Render.com)

เป็น Python ไฟล์เดียว ไม่มีไลบรารีเสริม ในโปรเจกต์มี `render.yaml` ไว้แล้ว

1. ที่ Render: **New → Blueprint** (หรือ **New → Web Service**) แล้วใส่ URL ของ repo นี้ (repo สาธารณะ ไม่ต้องเชื่อม GitHub)
2. ตั้งค่า (ถ้าสร้างแบบ Web Service เอง): Runtime **Python 3**, Build command `pip install -r requirements.txt`,

## v6: กฎค่าธรรมเนียม / การยกเลิก / การโอนเงิน (เจ้าของยืนยันแล้ว)

- **ยอดดีลขั้นต่ำ 100 บาท** – ตรวจทั้งตอนสร้างดีล ลงสินค้า/ที่พักในร้าน และตอนสั่งซื้อ/จองจากหน้าร้าน (ข้อความไทยชัดเจน)
- **ค่าโอนออก 30 บาท/วัน** (ผู้ขายจ่าย) – รอบโอนรายวันรวมทุกดีลเป็นการโอนครั้งเดียว หักค่าโอน 30 บาท **ฟรีเมื่อยอดรวม ≥ 1,000 บาท** · ยอดไม่พอค่าโอน → ยกไปรอบถัดไป · แสดงในหน้าสร้างดีล หน้าจ่ายเงิน และหน้า “เงินขายของฉัน” (ยอดรวม − ค่าโอนออก − ค่าปรับ = ยอดที่จะได้รับ + ประวัติรอบโอน)
- **ผู้ซื้อยกเลิกเอง** หลังจ่าย ก่อนผู้ขายส่งของ (ปุ่มใหม่ในดีลสินค้า) หรือผู้เข้าพักยกเลิกในช่วงยกเลิกฟรี → คืนเงินหัก **ค่าดำเนินการ 2% ขั้นต่ำ 10 บาท** · หน้ายืนยันแสดงยอดจ่าย/ค่าดำเนินการ/ยอดคืนจริง
- **ผู้ขาย/เจ้าของผิด** (ผู้ขายยกเลิกหลังรับเงิน, เจ้าของที่พักยกเลิก, ส่งไม่ทัน, ทีมงานตัดสินคืนเงิน) → ผู้ซื้อได้คืนเต็มรวมค่าธรรมเนียม + บันทึก **ค่าปรับเท่าค่าธรรมเนียม** หักจากยอดโอนถัดไป (ตาราง `records`) · หน้าแอดมินมีการ์ด “ผู้ใช้ที่ต้องจับตา”: ผู้ขายถูกปรับ ≥ 3 ครั้งใน 30 วัน และผู้ซื้อแพ้ข้อพิพาท ≥ 3 ครั้งใน 90 วัน (เสนอระงับบัญชี)
- **คืนบางส่วน** → ค่าธรรมเนียมคิดจากยอดที่ผู้ขายได้จริง (2% ขั้นต่ำ 20 บาท) เก็บใน `deals.fee_charged`
- **หลังผู้ขายส่งของ/ส่งมอบแล้ว** (เลขพัสดุ, หลักฐานแมสเซนเจอร์, ถึงเวลาเช็คอิน) ผู้ซื้อยกเลิกไม่ได้ – ปุ่มถูกซ่อน และ API ตอบ 400 พร้อมบอกให้ยืนยันรับของหรือแจ้งปัญหา
- ข้อตกลง (/terms): ลบหมายเหตุร่างข้อ 6.5 · ปรับข้อ 5.5, 6, 8.4, 8.6, 9.4–9.5, 10, 11 และกล่องสรุปสั้นๆ
- API ใหม่/เปลี่ยน: `GET /api/payouts` (เพิ่ม `next`, `penalty_owed`, `penalties`, `batches`, `rule`) · `POST /api/admin/payouts/run` (คืน `batches`) · `GET /api/deals/:code` (เพิ่ม `cancel_preview`, `buyer_cancel_charge`, `payout_rule`, `cancel_charge`, `penalty`, `fault`, `fee_charged`) · `GET /api/admin/overview` (เพิ่ม `flags`)
